Perjalanan Belajar HTML sampai CSS

Ditulis oleh Aprisa pada 13 Mei 2026 - FTI UNISKA

Ini adalah paragraf pertama saya. Di pertemuan 1 sampai 4, saya belajar bagaimana membangun web dari nol. Awalnya hanya teks biasa, sekarang sudah bisa pakai warna dan tipografi yang konsisten.

Paragraf kedua ini cerita tentang Tugas 2. Waktu itu saya masih bingung cara menampilkan gambar. Ternyata kunci ada di alt text dan memastikan file gambar satu folder dengan file html. Foto ngoding.jpeg, kolam.jpeg, dan badminton.jpeg jadi saksi perjuangan.

Paragraf ketiga tentang Tugas 3, yaitu tabel dan form. Di sana saya belajar colspan dan rowspan untuk menggabungkan sel, serta validasi form dengan required dan type email. Kalau lupa isi, browser akan muncul pop-up merah.

"Belajar coding itu bukan tentang hafal sintaks, tapi tentang bagaimana kita memecahkan masalah selangkah demi selangkah."

Paragraf keempat masuk ke materi hari ini, Pertemuan 4 CSS Dasar. Di sini saya baru paham kenapa external CSS lebih baik dari internal. Satu file style.css bisa dipakai untuk banyak halaman, jadi kalau mau ganti warna, cukup ganti di satu tempat saja.

Paragraf kelima sekaligus penutup. Ke depannya saya ingin membuat web yang tidak hanya berfungsi, tapi juga enak dibaca. Dengan max-width 728px dan line-height 1.8, mata jadi tidak cepat lelah. Itu trik dari dosen yang saya pakai di blog ini.

Yang Sudah Saya Pelajari:

  • HTML Semantik: header, nav, main, article, footer
  • CSS Selector: elemen, class, id, descendant, child, pseudo-class
  • Tipografi dengan Google Fonts
